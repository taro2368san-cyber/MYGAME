# ここからやること（ロードマップ v2）

**目標：友人と最後まで遊べる「完成版」を作る**

前提

- マスは自分の作りたいように置く。ゲームの長さは、マスを削るのではなく、ほかの数値（週数、自転車、経験値など）で合わせる
- 上から順に進める。各ステップの「できあがり」を満たしたら次へ
- 担当の書き方：**あなた**＝自分で手を動かす、**Claude Code**＝実装を頼む、**チャット**＝ここで一緒に決める・仕様書を書く

---

## 完成の定義

次の8つがすべてできたら「完成」とする。

| # | 条件 |
|---|---|
| 1 | タイトルから始めて、キャラクターと最初のポケモンを選び、ゲームが始まる |
| 2 | 盤面のすべての町・道路・別マップに行ける（島はチケットで） |
| 3 | どのマスに止まっても、仮の文字や空欄のまま止まらない |
| 4 | ジム8つを回り、バッジ8個でチャンピオンロード・セキエイ高原に行ける |
| 5 | 決めた週数が来たら、結果発表とエンドロールが流れて終わる |
| 6 | 途中で保存して、続きから遊べる |
| 7 | PS4コントローラー2個で、最初から最後まで操作できる |
| 8 | 友人と標準の週数を1回通して、止まらずに終わる |

見た目（立ち絵、背景、音）がそろっているかは、完成の条件に入れない。仮の絵のままでも、上の8つができていれば「遊べる完成版」。素材は最後に差し替える。

## ステップ5：ゲームの長さを合わせる

盤面を作りたいように置いたうえで、**マスは変えずに**ほかの数値で長さを合わせる。

### 5-A 測る仕組み

| # | やること | 担当 |
|---|---|---|
| 5-A-1 | CPU4人だけで、画面を出さずに速く自動対戦する | Claude Code |
| 5-A-2 | 週ごとにCSVへ記録：各プレイヤーのバッジ数、先頭のLv、所持金、場所、バトルの数 | Claude Code |
| 5-A-3 | 乱数の種を変えて10回まとめて回す | Claude Code |

### 5-B 目標（仮）

- 標準の週数で、上位の人がバッジ8個に届く
- 下位の人でもバッジ4〜5個までは進む
- 主力のポケモンが2段階進化している

### 5-C マスを変えずに長さを合わせる方法

効きの大きい順。

| 方法 | 調整値・データ | 効き方 |
|---|---|---|
| 標準の週数を増やす | ゲーム設定の初期値 | いちばん素直。50週が足りなければ100週を標準に |
| 自転車を手に入れやすくする | ショップ・ボールマスの重み | 1回の移動が2〜4倍になる |
| サイコロの0を減らす | dice_zero_rate | 小さく効く |
| ワープを増やす | 盤面のワープ | 遠い場所を近道でつなぐ |
| NPC戦の番交代をゆるめる | 仕様書7.1.1 | 野生・トレーナー戦をその手番で終わらせれば、移動の手番が増える |
| 経験値を増やす | exp_coef | 戦う回数が減っても育つ |
| ジム・トレーナーのLvを下げる | gym_ace_level_〜、出現表 | 育ちきらなくても勝てる |

**できあがり**：標準の週数で、目標の3つを満たす。
