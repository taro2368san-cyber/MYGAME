# 謎のチケット・不思議なチケットの設定

使うファイル

| ファイル | 中身 |
|---|---|
| `チケットの行き先.csv` | チケットごとの行き先と重み（20行、どちらも合計100）。行き先ごとに渡る島マップを決めてある |
| `島マップ.csv` | 渡る先の島マップ9つ |
| `調整値_チケット.csv` | 変化までの週数、島にいられる手番の数 |

## 1. 手に入れ方

| チケット | 手に入れ方 |
|---|---|
| 謎のチケット | ポケベルでサカキを呼ぶ（ev_giovanni）／下位救済：バッジ3個以上、連続20週最下位、トレーナーの道具に空きがあると自動で入る（12章） |
| 不思議なチケット | 謎のチケットを持ったまま最下位で決まった週数を過ごすと、謎のチケットが変わる |

どちらもトレーナーの道具。店では買えず、売れない。

## 2. 使える場所：クチバシティの船着場（確定）

- クチバシティに「船着場」のマスを1つ置く
- 船着場に止まったとき、チケットを持っていれば「どちらのチケットを使う？／使わない」を選ぶ（案）
- 使うとチケットはなくなり、`チケットの行き先.csv` の重みで行き先を1つ抽選して、その島マップへ船で渡る
- クチバシティはエリア3（バッジ2個）なので、チケットを持っていても、バッジ2個までは使えない

## 3. 島マップ（確定：簡単なマップを用意する）

| 種類 | 島 | 中身 |
|---|---|---|
| 地方の島 | ジョウト島、ホウエン島、シンオウ島 | 草むらで、出現表のその島の欄のポケモンが出る |
| 伝説の島 | 南の孤島、やけたとう、ナナシマ、うずまき島A・B、不思議な島 | 引いた伝説が1体、シンボルとして現れる。そのマスに止まると野生戦（クイック、ボールを投げられる） |

**作りの手間を減らす工夫**（案）

- 島マップの形は2種類だけ作り、使い回す。「地方の島の形」と「伝説の島の形」。見た目（地面の色や飾り）だけ島ごとに変える
- どちらも10〜15マスの小さな島にする。港のマスから始まり、1周できる輪っかの道にする
- 伝説の島は、港から一番遠いところに伝説のシンボルのマスを置く。輪っかなので、どちら回りでも何手番かで着ける
- 1つの伝説の島に複数の伝説が割り当ててある（南の孤島ならラティオスかラティアス）。現れるのは引いた1体だけ

**島での動き**（案）

- 島では普通にサイコロを振って動く
- 港のマスに止まれば、いつでもクチバの船着場に戻れる
- 5手番（ticket_island_turns）を過ぎたら、自動でクチバの船着場に戻る
- 島はそのプレイヤーだけのエリアとして扱う。外からの妨害は届かない（3.4）。2人が同じ島に渡っていても、互いに別の島にいる扱いにする

## 4. 伝説（確定）

- **チケットのたびに別の個体として出る**。誰かがすでに同じ伝説を捕まえていても、自分の分が現れる
- 盤面のシンボル（ミュウツーと三鳥、6.3.1）とは別。チケットで三鳥を引いても、盤面のシンボルには影響しない
- Lvは表のとおり（ラティ兄妹・三犬・ルギア・ホウオウは45、三鳥・ミュウ・デオキシスは40）（案）
- 島にいる間に倒すか捕まえるかしないまま戻ると、その伝説はいなくなる（案）

## 5. 謎のチケット → 不思議なチケット

- 謎のチケットを手に入れたとき、変わるまでの週数を3〜5週からランダムに決める（ticket_change_weeks_min／max）
- 週終了フェーズで、そのプレイヤーが最下位（12章の順位用ポイント）なら1週数える
- 決めた週数に届いたら、謎のチケットが不思議なチケットに変わる。「謎のチケットが かがやきだした…！」のような通知を出す
- 最下位でない週は数えない（数え直しにはしない）（案）

## 6. Claude Code に頼むときの文

> 設計メモ/チケットの設定.md と、チケットの行き先.csv、島マップ.csv、調整値_チケット.csv をもとに、謎のチケットと不思議なチケットを実装して。
> 1. クチバシティに「船着場」のマス種類を足す。止まったときチケットを持っていれば、使うか選べるようにする
> 2. チケットを使ったら、チケットの行き先.csv の重みで行き先を1つ抽選する。乱数は処理役の中で振る
> 3. 島マップは「地方の島の形」「伝説の島の形」の2つを作り、島マップ.csv の9つで使い回す。どちらも港から始まる10〜15マスの輪っかの道にする
> 4. 地方の島では草むらで出現表のその島の欄を使う。伝説の島では、引いた伝説を港から一番遠いマスにシンボルとして置き、止まったら表のLvで野生戦にする。伝説はチケットのたびに別の個体
> 5. 島では港に止まるか、ticket_island_turns 手番を過ぎたら、クチバの船着場に戻る
> 6. 謎のチケットを手に入れたとき変化までの週数を決め、最下位の週だけ数えて、届いたら不思議なチケットに変える
> 7. 下位救済（バッジ3個以上・連続20週最下位・トレーナーの道具に空き）で謎のチケットを配る
> 8. 自己テストに、抽選の重み、島からの戻り方、変化の週数の数え方を足す
