# UI仕様書：メイン画面（盤面）

手番の間ずっと表示される画面。仕様書16章の「12 盤面と情報表示」「14 準備フェーズ」にあたる。

状態の表記：**確定**＝決定済み、**案**＝提案、**未定**＝後で決める

---

## 1. 画面の構成

```
┌───────────────────────────────────────────────┐
│ [A 週と天気]     [B 場所名]    [C 手番のプレイヤー     ] │
│                                    [D1 プレイヤー]│
│                                    [D2 プレイヤー]│
│ ┌────┐                             [D3 プレイヤー]│
│ │E   │                                            │
│ │メニ│         F ゲーム画面（盤面）                │
│ │ュー│                                            │
│ └────┘                                            │
│                [G メッセージ欄（必要なときだけ）]   │
└───────────────────────────────────────────────┘
```

| 部品 | 位置 | 内容 | 状態 |
|---|---|---|---|
| A 週と天気 | 左上 | 何週目と、今の天気 | 確定 |
| B 場所名 | 上の中央 | 手番のプレイヤーがいる場所 | 確定 |
| C 手番のプレイヤー | 右上（横長） | 今の手番の人の情報 | 確定（中身は未定） |
| D1〜D3 ほかのプレイヤー | 右側に縦に3つ | 手番でない人の情報 | 確定（中身は未定） |
| E メニュー | 左下 | 移動／どうぐ／マップ／ポケモン／システム | 確定 |
| F ゲーム画面 | 全体（背景） | 3Dの盤面、コマ、連れ歩きのポケモン | 確定 |
| G メッセージ欄 | 下の中央 | マスの結果やセリフ。出ているときだけ表示 | 案 |

**画面の大きさ**：1920×1080を基準に作り、ウィンドウの大きさに合わせて伸び縮みさせる（仕様書1.3、Canvas Scaler の Scale With Screen Size）。部品は画面の四隅・辺に寄せて置き、画面の比率が変わってもF（盤面）の真ん中をふさがないようにする。

---

## 2. 部品ごとの仕様

### A 週と天気（確定）

| 項目 | 表示 |
|---|---|
| 週 | 「23／50週」（今の週／全体の週数） |
| 天気 | 晴れ・雨・砂あらし・なしのアイコン。天気があるときは残りの週数も出す（「雨 あと2週」） |

- 週が進んだとき（週終了フェーズ）に更新する
- 週イベントが起きている間は、Aの下に小さく週イベント名を出す（「セール中」）（案）
- 最後の10週（換金所が閉まる）に入ったら、週の文字の色を変えて知らせる（案）

### B 場所名（確定）

- 手番のプレイヤーがいるマスの「場所」（盤面_マス.csv の場所の列）を出す。例：「1番道路」「トキワシティ」
- 別マップ（洞窟や島）の中にいるときは、その別マップ名
- 手番が変わったとき、コマが移動して場所が変わったときに更新する
- 見渡しモード（マップ）中は、カーソルで選んでいるマスの場所に切り替える（案）

### C 手番のプレイヤー（確定、中身は未定）

- 今の手番の人を、ほかの3人より大きく出す
- 枠の色はそのプレイヤーの色（キャラクターごとの色）
- **中身は後で定義する**。候補：名前、キャラクターの顔、所持金、バッジの数、順位、先頭のポケモン、状態（1回休みなど）

### D1〜D3 ほかのプレイヤー（確定、中身は未定）

- 手番でない人を、手番の順に上から並べる（次の手番の人が一番上）（案）
- 2〜3人で遊ぶときは、使わない欄を出さない
- **中身は後で定義する**。Cより情報を絞る想定（名前、所持金、バッジ、順位など）
- 手番が変わると、C と D の中身が入れ替わる。手番の人がCへ上がる動きを短いアニメーションで見せる（案）

### E メニュー（確定）

準備フェーズ（サイコロを振る前）にだけ出す。

| 項目 | 押すと | 使えないとき（グレー） |
|---|---|---|
| 移動 | 「○でサイコロを振る」の画面へ。○で振る、×でメニューに戻る | なし |
| どうぐ | アイテム一覧（トレーナーの道具4枠、ポケモンの道具6枠、ボールの数） | その手番にすでに1個使った |
| マップ | 見渡しモード（仕様書16.7） | なし |
| ポケモン | 手持ち一覧。並び替え、1体を選ぶと詳細 | なし |
| システム | 図鑑／職業／順位／イベントルール／設定／セーブ | なし |

- 1回休みの手番はメニューを出さない（仕様書5.2）
- 移動中、バトル中、他のプレイヤーへの割り込みの表示中は、メニューを隠す
- 項目の名前は、仕様書16.9の「アイテム／探索／入れ替え／その他」から、この画面の「どうぐ／マップ／ポケモン／システム」に置き換える（確定）

**操作**（コントローラー1を使う）

| ボタン | 動き |
|---|---|
| 十字キー上下 | 項目を選ぶ |
| ○ | 決定 |
| × | 1つ前に戻る（メニューの一番上では何もしない） |

キーボードとマウスでも同じ操作ができる（仕様書15.10.1）。

### F ゲーム画面（確定）

- 3D空間の平らな板の上にマスを置き、斜め見下ろしの固定カメラで映す。回転しない（仕様書14章）
- マスは円柱。マスの種類は色や上の飾りで見分ける（案）
- **プレイヤーのコマの横に、手持ちの先頭のポケモンがついて歩く**（確定）。先頭が変わると、ついて歩くポケモンも変わる。相手から見えるのも先頭だけ（仕様書16.5）なので、盤面を見れば誰が何を先頭にしているかが分かる
- ほかのプレイヤーのコマ（と、その先頭のポケモン）も盤面に出す。同じマスに複数いるときは少しずらして並べる（案）
- 手番が変わったら、カメラを手番の人のコマへ動かす。コマが移動している間はコマについていく
- 見渡しモード（マップ）のときだけ、カメラを平行移動と拡大・縮小できる

### G メッセージ欄（案）

- マスの結果、セリフ、通知を出す。下の中央、メニューと重ならない位置
- 文字送りの速さは固定。表示の途中で○を押すと全文を出し、全文が出たあとの○で次へ（仕様書1.3）
- 出ていない間は隠す

## 3. 場面ごとの表示

| 場面 | A | B | C・D | E メニュー | G |
|---|---|---|---|---|---|
| 準備フェーズ | ○ | ○ | ○ | ○ | 必要なとき |
| 移動中 | ○ | ○ | ○ | 隠す | 隠す |
| マスの結果 | ○ | ○ | ○ | 隠す | ○ |
| 見渡しモード | ○ | 選んだマスの場所 | ○ | 隠す | 隠す（マスの説明を別に出す） |
| バトル | 隠す | 隠す | 隠す | 隠す | バトル画面に切り替え |
| 週の進行・割り込みの通知 | ○ | ○ | ○ | 隠す | 大きく出す（仕様書17.5） |

## 4. 見た目

- 背景は明るい水色、部品は濃い青緑の枠に白い文字（いただいた案の配色）
- 部品の角は少し丸め、半透明にして、後ろの盤面が透けて見えるようにする（案）
- 手番の人の色を、C の枠とコマの足もとの輪に使う。誰の番かがひと目で分かる（案）

**素材について**：案の画像の人物とポケモンは仮の絵として扱う。実際の絵は、仕様書17.7の方針（本家から抜き出した素材は使わない。まずはタイプ色の丸と名前、後から自作の絵に差し替え）で用意する。

## 5. 決まっていないこと

| 項目 | 内容 |
|---|---|
| C・Dの中身 | 何を出すか（後で定義） |
| Cの位置の意味 | 「手番の人」を出す欄か、「プレイヤー1」に固定の欄か（この仕様書では手番の人として書いた） |
| G メッセージ欄の位置 | 下の中央でよいか |
| マスの見分け方 | 種類ごとの色や飾り |
| 週イベントと最後の10週の知らせ方 | Aにどう出すか |
