# UI仕様書：メイン画面とイベント画面

手番の間ずっと表示される「メイン画面」と、人物が話しかけてくる「イベント画面」の仕様。仕様書16章の「12 盤面と情報表示」「14 準備フェーズ」にあたる。

状態の表記：**確定**＝決定済み、**案**＝提案、**未定**＝後で決める

---

## 1. 画面の構成

```
┌───────────────────────────────────────────────┐
│ [A 週と天気]     [B 場所名]    [C 手番のプレイヤー     ] │
│                                    [D1 プレイヤー]│
│                                    [D2 プレイヤー]│
│ ┌────┐                             [D3 プレイヤー]│
│ │E   │                                            │
│ │メニ│         F ゲーム画面（盤面）                │
│ │ュー│                                            │
│ └────┘                                            │
│                [G メッセージ欄（必要なときだけ）]   │
└───────────────────────────────────────────────┘
```

| 部品 | 位置 | 内容 | 状態 |
|---|---|---|---|
| A 週と天気 | 左上 | 何週目と、今の天気 | 確定 |
| B 場所名 | 上の中央 | 手番のプレイヤーがいる場所 | 確定 |
| C 手番のプレイヤー | 右上（横長） | 名前、先頭のポケモン、バッジ8個 | 確定 |
| D1〜D3 ほかのプレイヤー | 右側に縦に3つ | 名前、先頭のポケモン、バッジの数 | 確定 |
| E メニュー | 左下 | いどう／どうぐ／マップ／ポケモン／ずかん／せってい | 確定 |
| F ゲーム画面 | 全体（背景） | 3Dの盤面、コマ、連れ歩きのポケモン | 確定 |
| G セリフ欄 | 下の中央 | マスの結果やセリフ。セリフがあるときだけ下からスライドして出る | 確定 |

**画面の大きさ**：1920×1080を基準に作り、ウィンドウの大きさに合わせて伸び縮みさせる（仕様書1.3、Canvas Scaler の Scale With Screen Size）。部品は画面の四隅・辺に寄せて置き、画面の比率が変わってもF（盤面）の真ん中をふさがないようにする。

## 2. 部品ごとの仕様

### A 週と天気（確定）

| 項目 | 表示 |
|---|---|
| 週 | 「23／50週」（今の週／全体の週数） |
| 天気 | 晴れ・雨・砂あらし・なしのアイコン。天気があるときは残りの週数も出す（「雨 あと2週」） |

- 週が進んだとき（週終了フェーズ）に更新する
- 週イベントが起きている間は、Aの下に小さく週イベント名を出す（「セール中」）（案）
- 最後の10週（換金所が閉まる）に入ったら、週の文字の色を変えて知らせる（案）

### B 場所名（確定）

- 手番のプレイヤーがいるマスの「場所」（盤面_マス.csv の場所の列）を出す。例：「1番道路」「トキワシティ」
- 別マップ（洞窟や島）の中にいるときは、その別マップ名
- 手番が変わったとき、コマが移動して場所が変わったときに更新する
- 見渡しモード（マップ）中は、カーソルで選んでいるマスの場所に切り替える（案）

### C 手番のプレイヤー（確定）

```
┌──────────────────────────────────────────┐
│ プレイヤー名   [先頭のポケモン]   [バッジ][バッジ]…（8個） │
└──────────────────────────────────────────┘
```

| 中身 | 表示 |
|---|---|
| プレイヤー名 | 名前入力で決めた名前（ひらがな6文字まで） |
| 先頭のポケモン | 手持ちの1番目のドット絵 |
| バッジ | 8個のバッジを横に並べる。取ったバッジは色つき、まだのバッジは黒い影（確定） |

- 今の手番の人を、ほかの3人より大きく出す
- 枠の色はそのプレイヤーの色（キャラクターごとの色）（案）

### D1〜D3 ほかのプレイヤー（確定）

```
┌──────────────────────────┐
│ プレイヤー名  [先頭のポケモン]  [メダル 5] │
└──────────────────────────┘
```

| 中身 | 表示 |
|---|---|
| プレイヤー名 | 同上 |
| 先頭のポケモン | 同上 |
| バッジ | 持っているバッジの数を、メダルの絵に数字で出す |

- 手番でない人を、手番の順に上から並べる（次の手番の人が一番上）（案）
- 2〜3人で遊ぶときは、使わない欄を出さない
- 手番が変わると、C と D の中身が入れ替わる。手番の人がCへ上がる動きを短いアニメーションで見せる（案）

### E メニュー（確定）

準備フェーズ（サイコロを振る前）にだけ出す。

各項目の左に、その行動を表す絵のアイコンを付ける。（確定）案の画像の色の丸は仮で、実際は道具や物の絵で表す。

| 項目 | アイコンの絵柄 | 押すと | 使えないとき（グレー） |
|---|---|---|---|
| いどう | くつ（👞） | 「○でサイコロを振る」の画面へ。○で振る、×でメニューに戻る | なし |
| どうぐ | つりざお（🎣） | アイテム一覧（トレーナーの道具4枠、ポケモンの道具6枠、ボールの数） | その手番にすでに1個使った |
| マップ | 地図（🗺️） | 見渡しモード（仕様書16.7） | なし |
| ポケモン | 未定（ボールの絵など）（案） | 手持ち一覧。並び替え、1体を選ぶと詳細 | なし |
| ずかん | 本（📕）（案） | 図鑑の画面（6章） | なし |
| せってい | スパナ（🔧） | 職業／順位／イベントルール／設定／セーブ | なし |

- 絵文字は絵柄の例。実際は同じ雰囲気の絵（画像）を用意して表示する。Unityでは絵文字のフォントが環境によって正しく出ないため、文字ではなく画像にする（案）
- グレーのときは、アイコンも文字と一緒に薄くする

- 1回休みの手番はメニューを出さない（仕様書5.2）
- 移動中、バトル中、他のプレイヤーへの割り込みの表示中は、メニューを隠す
- 項目の名前はひらがなで「いどう／どうぐ／マップ／ポケモン／ずかん／せってい」（確定）。図鑑は「せってい」の中から出して、メニューの項目にした。「せってい」の中には、職業・順位・イベントルール・設定（音量など）・セーブが入る

**操作**（コントローラー1を使う）

| ボタン | 動き |
|---|---|
| 十字キー上下 | 項目を選ぶ |
| ○ | 決定 |
| × | 1つ前に戻る（メニューの一番上では何もしない） |

キーボードとマウスでも同じ操作ができる（仕様書15.10.1）。

### F ゲーム画面（確定）

- 3D空間の平らな板の上にマスを置き、斜め見下ろしの固定カメラで映す。回転しない（仕様書14章）
- マスは円柱。マスの種類は色や上の飾りで見分ける（案）
- **プレイヤーのコマの横に、手持ちの先頭のポケモンがついて歩く**（確定）。先頭が変わると、ついて歩くポケモンも変わる。相手から見えるのも先頭だけ（仕様書16.5）なので、盤面を見れば誰が何を先頭にしているかが分かる
- ほかのプレイヤーのコマ（と、その先頭のポケモン）も盤面に出す。同じマスに複数いるときは少しずらして並べる（案）
- 手番が変わったら、カメラを手番の人のコマへ動かす。コマが移動している間はコマについていく
- 見渡しモード（マップ）のときだけ、カメラを平行移動と拡大・縮小できる

### G セリフ欄（確定）

- セリフがないときは出さない。盤面がそのまま見える
- セリフがあるときは、**画面の下からスライドして出てくる**。読み終わると下へ引っこむ
- 濃い緑の箱に白い文字、ふちを細い金色で囲む（案の絵の見た目）
- 文字送りの速さは固定。表示の途中で○を押すと全文を出し、全文が出たあとの○で次へ（仕様書1.3）
- マスの結果、トレーナーのセリフ、通知など、メイン画面で出す文字はすべてこの欄を使う

## 4. 見た目

- 背景は明るい水色、部品は濃い青緑の枠に白い文字（いただいた案の配色）
- 部品の角は少し丸め、半透明にして、後ろの盤面が透けて見えるようにする（案）
- 手番の人の色を、C の枠とコマの足もとの輪に使う。誰の番かがひと目で分かる（案）

**素材について**：案の画像の人物とポケモンは仮の絵として扱う。実際の絵は、仕様書17.7の方針（本家から抜き出した素材は使わない。まずはタイプ色の丸と名前、後から自作の絵に差し替え）で用意する。

## 5. イベント画面（確定）

人物が話しかけてくる場面で、メイン画面の上にかぶせて出す画面。

```
┌───────────────────────────────────────┐
│ （後ろのメイン画面はグレーになる）               │
│   ┌───────────────────────────────┐   │
│   │          場所の背景（草・水・町・洞窟・雪山）  │   │
│   │              ┌─────┐               │   │
│   │              │立ち絵│               │   │
│   │              │      │               │   │
│   │      ┌──────────────────┐      │   │
│   │      │ セリフ                    │      │   │
│   │      └──────────────────┘      │   │
│   └───────────────────────────────┘   │
└───────────────────────────────────────┘
```

| 部品 | 内容 | 状態 |
|---|---|---|
| 後ろのメイン画面 | グレーにして暗くする。操作はできない | 確定 |
| 場所の背景 | 草・水・町・洞窟・雪山の5種類の絵から、今いる場所に合うものを出す | 確定 |
| キャラクターの立ち絵 | 話しかけてくる人物の立ち絵を中央に | 確定 |
| セリフ欄 | 背景の下側に重ねる。選択肢（はい／いいえ）もここに出す | 確定 |

**流れ**（案）

1. メイン画面がグレーになる
2. 場所の背景が出て、立ち絵が出てくる
3. セリフを順に出す（文言のCSVの「順番」どおり）
4. 選択肢があれば選ぶ
5. バトルになるならバトル画面へ。ならなければ、立ち絵と背景が消えてメイン画面に戻る

**イベント画面を使う場面**（確定）

| 場面 | 人物 |
|---|---|
| ランダムイベント | モミ、チャンピオンたち、ポケベルで呼ぶ人 |
| 拠点の人 | ロケット団員、フジ老人、シルフの社長、博物館の研究員、オーキド博士 |
| ライバル | 7人 |
| ジムリーダー | 8人 |
| 職に関するトレーナー | 職業マスのトレーナー |

一般のトレーナー（たんぱんこぞうなど、職業マスでないトレーナー）とジムトレーナーは、イベント画面を使わず、メイン画面のセリフ欄だけで話す。立ち絵が要るのは上の人物だけになる。

**背景**（確定）：基本の5種類に、専用の背景7種類を足した12種類。

| 背景 | 使う場所 |
|---|---|
| ポケモンタワー | ポケモンタワー |
| シルフカンパニー | シルフカンパニー |
| サントアンヌ号 | サントアンヌ号 |
| ジム | ジムのマス |
| リーグ | セキエイ高原（ポケモンリーグ） |
| ポケモンセンター | ポケモンセンターのマス |
| ショップ | ショップのマス |
| 草 | 道路、森、サファリゾーン、地方の島 |
| 水 | 水道、海上マス、船着場、うずまき島 |
| 町 | 町、研究室、博物館 |
| 洞窟 | ダンジョン、イワヤマトンネル、ハナダの洞窟、ディグダの穴、ロケット団アジト、ポケモン屋敷、むじんはつでんしょ |
| 雪山 | シロガネ山 |

**選ぶ順番**（案）：上から順に当てはまるものを使う。

1. マスの種類に専用の背景があればそれ（ジム、ポケモンセンター、ショップ）
2. 場所に専用の背景があればそれ（ポケモンタワー、シルフカンパニー、サントアンヌ号、セキエイ高原）
3. どちらもなければ、場所の種別から基本の5種類を選ぶ

ジムの背景は8つのジムで共通の1枚にする（案）。マスのデータに「背景」の列を足せば、マスごとに上書きできる。

## 6. 図鑑の画面（確定）

メニューの「ずかん」から開く。準備フェーズのときだけ。

### 6.1 一覧

```
┌────────────────────────────────────────┐
│ {プレイヤー名}の ずかん     登録 45／275   捕まえた 30 │
├────────────────────────────────────────┤
│ 001 [絵] フシギダネ   ●                              │
│ 002 [影] ？？？                                       │
│ 003 [絵] フシギバナ   ○                              │
│  …                                                   │
└────────────────────────────────────────┘
```

| 表示 | 内容 | 状態 |
|---|---|---|
| 番号 | ポケモンシートの番号（1〜275） | 確定 |
| 絵と名前 | 登録したポケモンはドット絵と名前。まだのポケモンは黒い影と「？？？」 | 案 |
| しるし | ● 捕まえた、○ 倒しただけ（図鑑には登録される）、なし まだ | 案 |
| 数 | 上に「登録」と「捕まえた」の数 | 案 |

図鑑の登録は「倒す」か「捕まえる」で埋まる（仕様書6.5）。そのうえで、捕まえたかどうかを分けて見せる。イベントルール「いちばん多くの種類を捕まえた」の進み具合が、ここで分かる。

### 6.2 詳しく

一覧で1体を選んで○を押すと出る。登録したポケモンだけ。

| 表示 | 内容 |
|---|---|
| 基本 | ドット絵、名前、タイプ、弱点、特性 |
| 強さ | 種族値（HP、こうげき、ぼうぎょ、とくこう、とくぼう、すばやさ）と合計 |
| 技 | こうげき技、とくこう技、必殺技と、その効果 |
| 進化 | 進化の前後と、その条件 |
| 出る場所 | 出現表で、そのポケモンが出る場所（未解放のエリアも出すか、出さないかは未定） |
| 旅の記録 | **初めて登録した週と場所**（「12週目 トキワの森で 捕まえた」）（案） |

旅の記録は、エンドロール（仕様書1.5）と同じ記録を使う。図鑑を開くたびに、そのポケモンとどこで出会ったかを思い出せる。

### 6.3 ほかのプレイヤーの図鑑（案）

L1／R1で、ほかのプレイヤーの図鑑に切り替えられる。見られるのは一覧と、登録したポケモンの詳しくまで。相手がどんなポケモンに出会ってきたかが分かり、コンセプト（相手の旅を知る、仕様書1.0）につながる。

### 6.4 操作

| ボタン | 動き |
|---|---|
| 十字キー上下 | 1体ずつ動く |
| 十字キー左右 | 1ページ（10体）ずつ動く |
| ○ | 詳しくを開く |
| × | 一覧に戻る／メニューに戻る |
| L1／R1 | ほかのプレイヤーの図鑑に切り替え（案） |
| △ | タイプで絞り込み（案） |

## 7. バトル画面

### 7.1 画面の構成（確定）

```
┌──────────────────────────────────────────┐
│ [自分のポケモン：HP]   残りターン   [相手のポケモン：HP] │
│                           8                      │
│                                                  │
│   （自分のポケモン）              （相手のポケモン）    │
│    ＝＝台座＝＝                    ＝＝台座＝＝       │
│                                                  │
│   [△ 必殺]                      [△ カウンター]     │
│ [□ こうげき][○ とくこう]   [□ ぼうぎょ][○ とくぼう]  │
│ [R1 どうぐ]     [  セリフ欄  ]        [R1 逃げる]  │
└──────────────────────────────────────────┘
```

| 部品 | 内容 | 状態 |
|---|---|---|
| 背景 | 5種類（草・海・洞窟・室内明・室内暗）。その上に天気のアニメーションを重ねる | 確定 |
| 天気 | なし・晴れ・雨・砂あらしのアニメーション（降る雨、舞う砂など） | 確定 |
| 名前とHP | 左上に自分、右上に相手 | 確定 |
| 残りターン | 上の中央。ラウンドの上限（仕様書7.1.1）までの残り。1ラウンドごとに1減り、0になったラウンドで終わる。次のラウンドはなく、判定に進む | 確定 |
| ポケモン | 左に自分、右に相手。それぞれ台座の上 | 確定 |
| コマンド | 攻撃側のポケモンの下に攻撃の3つ＋どうぐ、防御側のポケモンの下に防御の3つ＋逃げる。ボタンの記号つき | 確定 |
| セリフ欄 | 下の中央。メイン画面と同じ見た目 | 確定 |

メイン画面の部品（週、場所名、プレイヤーの欄、メニュー）は、バトル中は出さない。

**攻撃側を少し大きく、防御側を少し小さく**見せる。どちらが攻撃しているかが、ポケモンの大きさでひと目で分かる。

**コマンドはポケモンについていく**（確定）。攻撃側のポケモンの下に攻撃のコマンド、防御側のポケモンの下に防御のコマンドを出す。攻守が交代したら、左右のコマンドの組も入れかわる。

### 7.2 コマンドとボタン（確定）

| ボタン | 攻撃側 | 防御側 | ガード |
|---|---|---|---|
| □ | こうげき（物理攻撃） | ぼうぎょ（まもる） | □どうしなら成功 |
| ○ | とくこう（特殊攻撃） | とくぼう（特殊守り） | ○どうしなら成功 |
| △ | 必殺（必殺技） | カウンター | △どうしなら成功（反射） |
| R1 | どうぐ | 逃げる（プレイヤー戦では降参） | — |
| × | （使わない。どうぐの一覧や確認の画面で「戻る」「いいえ」） | 同左 | — |

**どうぐと逃げるの置き場所**（確定）：どちらも4つ目のコマンドとしてR1に置く。仕様書7.3のとおり、どうぐは攻撃側、逃げるは防御側のコマンドなので、同じボタンでも出てくるのはその時の役割の方だけになる。

- □○△と離れた肩のボタンなので、ガードのつもりで押し間違えにくい
- ×は「戻る」の決まりのまま残す。どうぐの一覧を開いた後に×で閉じられ、逃げるの確認で×を押せば「いいえ」になる
- 画面では、攻撃側なら左下（または右下）に「R1 どうぐ」、防御側なら「R1 逃げる」を、3つのコマンドの下に小さく出す

**同じ記号どうしだとガード成功**になるよう、攻撃と防御を同じボタンに並べた。相性表（仕様書7.3）を覚えなくても、「相手と同じボタンを押せば守れる」と分かる。

- コマンドの色：□はうすい橙、○は水色、△はうすい緑（案の絵の色）
- 必殺がクールダウン中のときは、△をグレーにして押せなくする
- 逃げるは即敗北にもなる操作なので、押したら確認を1回出す（×で取り消し）
- どうぐを押すと、使えるアイテムの一覧が開く。1つ選んで○で使う。×で閉じればコマンド選びに戻る
- 押した瞬間に決まり、取り消せない（仕様書7.3）
- 括弧の中は仕様書での呼び名。画面にはひらがなの呼び名を出す

### 7.3 バトルの流れ

**① 登場**（確定）

- 自分のポケモン：モンスターボールから出てくる
- 野生のポケモン：画面の横からスライドして入ってくる
- トレーナーのポケモン：モンスターボールから出てくる（案）

**② 先攻・後攻のカード**（確定）

- 画面の下からカードが出てくる。枚数はすばやさの差で2〜4枚（仕様書7.1.2）
1. カードを**表向き**で並べ、先攻と後攻が何枚ずつかを見せる
2. 全部を**裏返し**、並びを**混ぜる**
3. 仕掛けた側（NPC戦ならプレイヤー）が1枚選ぶ。十字キー左右で選び、○で決定
4. 選んだカードを**めくって**結果を見せ、カードが下へ消える

表向きで見せてから混ぜるので、すばやさで有利な側は「先攻のカードが多い」ことを確かめたうえで引ける。

**③ コマンドを選ぶ**（確定）

- 攻撃側はポケモンが大きく、防御側は小さくなる
- それぞれ自分の側のボタンを押す。プレイヤー戦では2Pのコントローラーも使う
- 選んでいる間は、どのボタンを押したかを画面に出さない。押した側には「選択済み」と小さく出す（案）

**④ 結果発表**（確定）

- **選んだコマンドだけを残し、選ばなかったコマンドをグレーにする**
- 選んだ側のポケモンを少し縦に縮ませる（ぐっと力をためる動き）
- そのポケモンのまわりに、**選んだコマンドの色のオーラ**を出す（□なら橙、○なら水色、△なら緑）
- 攻撃側、防御側の順に見せる（案）

**⑤ 技の演出**（確定）

- 攻撃側から防御側へ、技のエフェクトを出す
- 技名をセリフ欄に出す（「ニドリーノの どくづき！」）（案）
- ダメージ、急所、ガードの成否、状態異常などをセリフ欄に出す

**⑥ 攻守の交代**（確定）

- 両方のポケモンが**画面の横へスライドして出ていき**、また**横からスライドして入ってくる**
- 入ってくるとき、攻撃側と防御側の大きさが入れかわる
- 残りターンが1減る

ここまでで1ラウンド。決着がつくまで③〜⑥をくり返す。

**野生戦**では、攻守が1往復するたびに「ボールを投げる？」の確認を出す（仕様書7.1.3）。またNPC戦では1往復ごとにすごろくの番が変わるので、次の手番でバトル画面に戻ったときは①の登場から見せる（案）。

## 8. 素材について

案の画像の人物・ポケモン・背景は、仮の絵として扱う。実際の絵は、仕様書17.7の方針で用意する。

- ポケモンとトレーナーのドット絵：本家から抜き出した素材は使わない。まずはタイプ色の丸と名前、後から自作の絵に差し替える
- 立ち絵：本家の公式イラストは使わず、自作か、利用規約を確認したフリー素材
- 背景：利用規約を確認したフリー素材（イラストACなど）か自作。使う前にサイトごとの規約を確認する
